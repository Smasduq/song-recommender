# Contributing to Song Recommender

We welcome contributions! Here's how you can help:

## Ways to Contribute

- **Improve the skill logic**: Suggest better ways to match songs to preferences
- **Enhance question guidance**: Add more natural phrasing examples
- **Add use cases**: Document more scenarios where this skill is useful
- **Fix documentation**: Improve clarity, fix typos, add examples
- **Share feedback**: Report issues or suggest improvements

## Getting Started

1. Fork the repository
2. Make your changes
3. Test your changes if applicable
4. Submit a pull request

## Guidelines

- Keep changes focused and minimal
- Update documentation when modifying behavior
- Follow existing style and formatting
- Be respectful and constructive

## Questions?

Feel free to open an issue for discussion.
