# Song Recommender

A skill that helps AI agents recommend songs based on a person's music taste, mood, and situation. The agent asks a few short questions, searches for real songs, and recommends three tracks with explanations for why each fits.

## What it does

- Asks targeted questions about mood, taste, and preferences
- Searches for real songs based on the user's input
- Recommends 3 songs with personalized explanations
- Provides links to find the songs legally
- Offers follow-up suggestions

## When to use

Use this skill when someone wants music recommendations, such as:
- "Recommend me a song"
- "What should I listen to?"
- "Find music for my mood"
- "Songs for the gym/workout"
- "Songs for a road trip/study session"
- "Music for a gift playlist"

## How it works

1. **Collects preferences**: Mood/occasion, favorite artists/songs, genres/languages/eras, who it's for
2. **Summarizes taste**: Creates a quick confirmation of understanding
3. **Searches candidates**: Finds relevant songs based on criteria
4. **Verifies**: Confirms songs exist before recommending
5. **Recommends 3**: Mixes safe picks with discovery
6. **Explains why**: Each pick has a reason tied to stated preferences
